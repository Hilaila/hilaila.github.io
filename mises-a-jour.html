    • GouvernanceGovernance

      Sauvegarde chiffrée de la base chaque semaine, vérifiée par une restauration d'essai automatique.Weekly encrypted database backup, checked by an automatic test restore.

    • ApplicationApp

      Accessibilité : textes plus contrastés, zoom permis sur toutes les pages, onglets, questions et ajout de documents utilisables au clavier, élément actif bien visible ; contrôle automatique selon les normes WCAG 2.2 (niveaux A et AA).Accessibility: higher-contrast text, zoom allowed on every page, tabs, questions and document upload usable from the keyboard, clearly visible focus; automatic check against WCAG 2.2 (levels A and AA).

02

Comment nous publionsHow we publish

  1. Chaque modification est d'abord vérifiée : tests automatiques du serveur et contrôle de toutes les pages sur écran de téléphone, en français et en anglais.Every change is checked first: automatic server tests and a check of every page on a phone screen, in French and English.
  2. Elle n'est publiée qu'avec l'accord du fondateur.It is only published with the founder's approval.
  3. Le code de l'application est public : chacun peut consulter son historique sur GitHub.The app's code is public: anyone can read its history on GitHub.
  4. Les incidents sont notés dans un registre suivi par l'administrateur, jusqu'à leur résolution.Incidents are recorded in a register followed by the administrator until they are resolved.
