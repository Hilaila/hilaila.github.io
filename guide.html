05

Questions fréquentesFrequently asked questions

Pourquoi faut-il un KYC Pi ?Why is Pi KYC required?

Pour que chaque demande vienne d'une personne réelle et vérifiée. Le KYC est fait et contrôlé par Pi Network ; GeoTerraChain QFS ne vous demande aucun document d'identité.So that every request comes from a real, verified person. KYC is done and checked by Pi Network; GeoTerraChain QFS never asks for an ID document.

Qu'est-ce que le burn de 0,5 % ?What is the 0.5% burn?

À chaque tokenisation, 0,5 % de l'offre en GTCπ est destiné au burn. Exemple : pour 1 GTCπ, 0,005 est brûlé et 0,995 reste. Ce mécanisme ne garantit aucune valeur ni aucun rendement.For each tokenization, 0.5% of the GTCπ offer goes to the burn. Example: for 1 GTCπ, 0.005 is burned and 0.995 remains. This mechanism guarantees no value and no return.

Le jeton de test a-t-il une valeur ?Does the test token have any value?

Non. En phase pilote, le jeton GTCπ est émis sur le réseau de test Stellar pour tester le parcours. Il ne s'échange pas et ne représente aucun droit sur l'actif.No. During the pilot phase, the GTCπ token is issued on the Stellar test network to test the journey. It cannot be traded and grants no right over the asset.

Combien de π faut-il ?How much π do I need?

0,001 π pour le paiement test, plus les frais de réseau affichés par le Pi Wallet avant confirmation.0.001 π for the test payment, plus the network fees shown by the Pi Wallet before you confirm.

Mes documents sont-ils envoyés ?Are my documents uploaded?

Oui, juste après la soumission, dans un espace de stockage privé, avec leur empreinte SHA-256. Seuls les vérificateurs de la plateforme peuvent les ouvrir, par un lien valable 5 minutes. Si l'envoi est interrompu, appuyez sur « Réessayer l'envoi ».Yes, right after submission, to a private storage space, with their SHA-256 fingerprint. Only the platform's verifiers can open them, through a link valid for 5 minutes. If the upload is interrupted, tap “Retry upload”.

« Pi ne répond pas encore » : que faire ?“Pi is not responding yet”: what should I do?

La connexion ne fonctionne que dans le Pi Browser. Si le lien s'est ouvert dans Chrome ou WhatsApp, ouvrez le Pi Browser et tapez hilaila.github.io. Sinon, appuyez de nouveau sur « π Connexion ».Sign-in only works inside the Pi Browser. If the link opened in Chrome or WhatsApp, open the Pi Browser and type hilaila.github.io. Otherwise, tap “π Sign in” again.

Le paiement a été interrompu : que faire ?The payment was interrupted: what should I do?

Reconnectez-vous avec Pi : un paiement commencé est finalisé automatiquement à la connexion suivante. Un paiement sans transaction est annulé par Pi Network.Sign in with Pi again: a started payment is completed automatically at the next sign-in. A payment with no transaction is cancelled by Pi Network.

Où voir mes demandes ?Where can I see my requests?

Dans « Mon espace », onglet « Mes actifs ». Gardez aussi la référence GTC-… et le TXID affichés à la fin.In “My space”, “My assets” tab. Also keep the GTC-… reference and the TXID shown at the end.
